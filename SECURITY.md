# Security Policy

Crowsnest handles cluster credentials, so we take security reports seriously.

## Reporting a vulnerability

Please **do not** report security issues in public issues or discussions.

Instead, use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/altiros/crowsnest/security/advisories/new).

Please include:

- the Crowsnest version and platform (macOS / iPadOS version),
- a description of the issue and its impact,
- steps to reproduce, if possible.

Never include real credentials (kubeconfigs, tokens, certificates) in a report. Use throwaway or redacted data.

We will acknowledge your report as soon as possible and keep you informed while we work on a fix.

## Supported versions

Security fixes are released for the latest version only. Please update before reporting.
